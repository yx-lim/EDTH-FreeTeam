# Working rules for this repo

- After each finished implementation (a feature, fix or doc change that works), commit it and push straight to `main`
  on the `freeteam` remote (github.com/yx-lim/EDTH-FreeTeam, public). One commit per implementation, with a clear
  message, so the history reads as a work log.
- The repo is public: never commit `.env`, API keys or tokens. Check the diff for secrets before every push.
- Several Claude sessions may work in this folder at once. Stage only the files your own change touched.
