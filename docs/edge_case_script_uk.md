# Ukrainian edge-case script (Irpin zone)

100 radio reports in Ukrainian, Russian and surzhyk, one a minute, set in Irpin (pick **Ірпінь** in the zone dropdown). Each line says what should happen. Callsigns and codenames are invented (`data/callsigns.json`, `data/zones/irpin/codenames.json`).
